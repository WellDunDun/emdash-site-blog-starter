# Open Graph Image Prompt

Use this prompt with an image-generation tool to create a production Open Graph image.

If repo skills are available, load .agents/skills/emdash-site-blog-starter/SKILL.md first and gather the visual brief before generating assets.

```text
Create a 1200x630 Open Graph image for an AI-ready site + blog.

Brand/product name: Brightline Studio
Tagline: Launch-ready websites for ambitious teams
Audience: B2B founders, agencies, and operators
Visual direction: polished product or service brand, confident, crisp, editorial, not generic stock art
Core motif: clear market signal, workflow clarity, sharp point of view, fast decision-making
Palette: use the product brand colors from the site CSS if provided; otherwise use a restrained light background with one strong accent
Typography: large readable product name, short tagline, high contrast, safe margins
Composition: 1200x630, centered or left-weighted text, visual system on the opposite side, no tiny UI text, no screenshots unless supplied
Avoid: random gradient blobs, fake logos, unreadable chart labels, cluttered dashboards, dark blurry backgrounds, cliche rocket/megaphone imagery

Output requirements:
- PNG or JPG
- 1200x630
- Text must be legible at small preview sizes
- Leave safe padding around every edge
```
